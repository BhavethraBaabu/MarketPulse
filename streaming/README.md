# MarketPulse – Day 4: Kafka Streaming

## Objective
Build an event-driven stock market data pipeline using Apache Kafka.

## Technology
- Python
- Apache Kafka
- confluent-kafka
- PostgreSQL

## Planned Features
1. Kafka Producer to publish stock price events.
2. Kafka Consumer to process stock events.
3. PostgreSQL integration.
4. Retry mechanism for failed events.
5. Dead Letter Queue (DLQ).
6. Failed event replay.

## Current Progress
- Installed confluent-kafka Python client.
- Configured the MarketPulse Python virtual environment.
- Docker installation pending.
- Kafka broker setup pending.
